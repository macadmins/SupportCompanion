## Description

Support Companion is a macOS app that IT deploys to give people one place to see the
state of their Mac and fix common problems themselves, instead of opening a ticket.

It surfaces device, storage and battery details, patching progress and pending updates,
and, in Fleet mode, the compliance checks failing on the Mac along with the steps to
resolve them. People can install approved software from a self-service catalog, run
actions you define, and request time-limited admin rights with a logged reason. The
whole app carries your organisation's name, logo and accent colour.

It reads from whatever you already run: **Munki**, **Jamf Pro**, **Microsoft Intune**,
**Fleet**, or plain system profiler.

For setup, see the [Wiki](https://github.com/macadmins/supportcompanion/wiki).
